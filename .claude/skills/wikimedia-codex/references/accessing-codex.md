# Accessing Codex

Condensed from `codex-docs/docs/using-codex/accessing-codex.md` (canonical).

Codex is the design system for Wikimedia and provides:

- **Style Guide** — for creating harmonious designs across Wikimedia
- **Design tokens** — for writing styles consistent with the Codex Style Guide
- **Icons** — a collection of icons with language and directionality variants
- **Components** — for building usable, accessible, translatable applications
- **Composables** — common patterns from the Codex codebase

Each feature includes:
- Wide-ranging support for internationalization and global usage
- Web accessibility baked in
- Comprehensive browser and device support
