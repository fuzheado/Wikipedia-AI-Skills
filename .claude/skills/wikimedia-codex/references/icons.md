# Icons

Condensed from `codex-docs/docs/icons/overview.md` (canonical).

Codex contains a collection of monochrome icons used to visually convey actions or information.
The full list (per directionality and language) is in `docs/icons/all-icons.md`.

## Using icons

Use icons through the **Icon component** or through other components that accept icons as props;
you can also embed the icon inside another component's slot (e.g. an icon inside a Button).

- **npm**: see `references/developing.md` (installation + using icons).
- **MediaWiki**: https://www.mediawiki.org/wiki/Codex#Using_Codex_icons

## Contributing icons

To add an icon, see `docs/contributing/contributing-icons.md` (icons live in the
`@wikimedia/codex-icons` package). Icon files are in `codex-source/packages/codex-icons/src/`.
