# Second rescue: a live account with deleted photos (184802432@N05)

Production run, June 2026, that generalised the skill from "deleted account" to
"**live account that deleted some photos**". Photographer: Stefan Müller
(`184802432@N05` / alias `stefan-mueller-climate`), ~16,435 live photos, first
upload Oct 2019. Everything below is what this run actually observed.

## Setup

- The **account still exists**, so the "deleted" set is not the whole account.
  Enumerate the Wayback photo IDs (both NSID + alias URL forms), fetch the full
  live photostream via the Flickr API, and the **deleted set = archived − live**.
- Photographer already maintains `Category:Photographs by Stefan Müller` on
  Commons (6,903 files). So the first Commons check is a **back-fill**: match
  the category's title-IDs against the deleted set, then insource-search the
  remainder. Result: **325 of 350 deleted photos were already on Commons** —
  the photographer had uploaded them before deleting them from Flickr.

## Lesson 1 — "no images" was a CDX query bug, not a real absence

First pass concluded **no image bytes were archived** (which contradicted the
Internetstiftelsen run). Wrong. The wildcard queries were malformed:

- `url=live.staticflickr.com/65535/<id>_*` with **`matchType=prefix`** → 0 rows.
  With `matchType=prefix` the trailing `*` is treated as a **literal** character,
  so it matches nothing (no real URL ends in `_*`).
- `url=*.staticflickr.com/*<id>_*` (leading domain `*`) → returned only generic
  `staticflickr.com` **root** captures (2007–2013), useless.
- **Correct form**: `url=live.staticflickr.com/65535/<id>_*` with **no
  matchType** → returns every size capture for that ID (all secrets, all sizes).

The takeaway: **always verify "no capture" with a plain trailing-wildcard query
before concluding an image is lost.** See `scan-cdx-images.py`.

## Lesson 2 — modern image host is `live.staticflickr.com/65535/…`

Older accounts (farm/c1 staticflickr) may not hold modern uploads. Photos
uploaded in the last ~5 years are served from `live.staticflickr.com/65535/`.
The Wayback crawler followed `<img>`/og:image URLs there and stored the bytes.
Also: **one photo can have several secrets** across captures
(`52117333588_79b0b0e5ba_b.jpg` and `52117333588_3e73035cbe_n.jpg`); the
wildcard scan surfaces them all.

## Lesson 3 — Flickr stopped server-rendering photo pages (~Feb 2023)

The archived 2023–2025 photo pages are **SPA shells**: 77–106 KB, no
`modelExport`, no title/license/description/dates. But the crawler still
followed the page's og:image URL, so **images were archived anyway**. Net rule:

- **page capture < ~110 KB, no `modelExport`** → metadata unrecoverable from IA,
  but the image may still be recoverable via the CDX wildcard scan.
- Do **not** report such photos as "nothing archived"; they are
  **image-only recoveries**, blocked from Commons only by the missing license.

## Lesson 4 — 429 captures

Some 2025 image captures return `429` (text/html) — the Wayback got
rate-limited by Flickr and stored the 429 response. Skip `statuscode != 200`
and non-image mimetypes; other timestamps usually have a real 200 image.

## Lesson 5 — deleted photos: license evidence and FlickreviewR

For a photo **deleted from Flickr**, `{{FlickreviewR}}` cannot run (it checks
the live page). The archived page's `photo-models[0].license` still gives the
license id; cite the **Wayback capture** as the source URL in the Information
block and as license evidence. Upload with `{{cc-by-2.0}}` (or whatever the
archived license says) and a note that the Flickr page is deleted but archived.
A Commons reviewer may ask for confirmation — point at the archived URL.

## Lesson 6 — metadata-only vs image-only is not a dichotomy

For the 4 fully recoverable photos the archived pages (2022) had a full
`modelExport`: title, description, license **id 4 = CC BY**, taken-date, and
the sizes block. Largest archived image sizes: 1024px, 640px, 1600px, 640px —
the original (`o`) was **not** archived for any of them, so best-effort sizes
were downloaded. For the 17 image-only photos the model was absent, so no
license ⇒ **skipped from the manifest** (BY/BY-NC/BY-NC-ND mix would make NC
photos ineligible for Commons).

## Lesson 7 — large accounts: photostream pagination trick

The Flickr photostream API/HTML is paginated at 100/page. For 16,435 photos
the paged model extraction produced 164+ requests; cache every page to disk so
a rerun skips what is already fetched. The current-photostream comparison
(`archived − live`) is O(1) with a set diff, not per-photo API calls.
